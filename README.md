# Freight invoice reconciliation and dispute workbench

Private, local-only source construction. Runtime unverified; independent admission, human audit and evaluation pending. No benchmark or savings claim.

The source implements deterministic linehaul, fuel, detention and liftgate calculations; exact carrier-scoped linking and duplicate allocation; original-source evidence checks; append-only review decisions; and inert dispute drafts requiring current human approval. Monetary calculations use integer cents and Decimal rates. Missing evidence produces an explicit unknown outcome.

The CLI, mock-only extraction ports, origin ledger and diagnostic evaluation tools are written but have not been imported or executed. No dependencies have been installed or locked. The native PDF adapter, record/field provenance and persisted link-ruling journey are still being completed. Builder examples are original illustrative inputs, not independent evaluation data.
