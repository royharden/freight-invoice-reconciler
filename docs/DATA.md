# Data boundary

Only builder-owned, original synthetic examples may appear under
fixtures/builder/. They are labeled builder_non_independent; they are not
admission data, gold answers, pilot/H-dev, independent H-out or held-out inputs.
No external dataset, client record, real carrier or copied repository data is
included. A builder example is not evidence of benchmark adequacy or accuracy.

Native PDF bytes must be hashed raw; extracted page text is an independently
hashed archived edition. Text pointers use Unicode codepoint offsets and exact
quote hashes. Normalization never rewrites an archived source. Runtime databases
belong outside repositories and OneDrive.

Future independent authoring, custody, actual rights review, licenses and human
audits are pending. No independent data or human evidence is authored here.
